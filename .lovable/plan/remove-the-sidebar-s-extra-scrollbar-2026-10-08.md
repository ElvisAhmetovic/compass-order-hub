# Remove the sidebar's extra scrollbar

## Change
- Remove the sidebar's fixed viewport height and sticky positioning.
- Remove independent scrolling from the menu area.
- Let the sidebar and page use the browser's single main scrollbar, so the menu moves naturally with the page.
- Keep the existing sidebar colors, links, groups, permissions, and badges unchanged.

## Verification
- Confirm long dashboard pages show only one vertical scrollbar.
- Confirm all sidebar entries remain reachable by normal page scrolling.
- Check the current page still highlights correctly and the layout remains aligned.
